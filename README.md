# Adidas Sales Analysis Dashboard

## 📌 Project Overview
This project analyzes Adidas sales data using Microsoft Excel and Power BI. The dashboard provides an interactive view of sales, profit, units sold, products, regions, states, retailers, and sales methods.

## 🛠️ Tools Used
- Microsoft Excel
- Power BI
- Data Visualization

## 📊 Dashboard Features
- Total Sales
- Total Profit
- Total Units Sold
- Average Price per Unit
- Profit Margin
- Monthly Sales Analysis
- Sales by State
- Sales by Region
- Sales by Product
- Sales by Retailer
- Sales Method Analysis
- Interactive Year and Month Filters

## 💡 Key Metrics
- Total Sales: $899.9M
- Total Profit: $332.1M
- Total Units Sold: 18M
- Average Price per Unit: 45.22
- Profit Margin: 42.30%
